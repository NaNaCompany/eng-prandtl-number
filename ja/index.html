計算結果

プラントル数 Pr

—

値を入力し「計算する」を押してください。

公式

Pr = μc_p/k

適用条件

同じ流体状態における μ,c_p,k>0 を用います。μ は粘性係数であり、動粘度ではありません。非ニュートン流体の有効物性値は推定しません。

表示値は浮動小数点数による近似値です。設計安全率や、入力されていない誤差要因は計算しません。
